# Task Decomposition Index - math-skills

Date: 2026-06-25
Project: Statistics CLI in Go

## Purpose

Build a command-line program that reads a file containing one number per line and prints:

- Average
- Median
- Variance
- Standard Deviation

The output values must be rounded integers and must follow the exact audit format.

## Source Requirements

- `AI/info.txt`: project brief and required output format.
- `AI/audit.txt`: functional audit checklist and README bonus requirement.
- `AI/AGENT.md`: development rules, edge cases, testing expectations, and Go tooling checks.

## Implementation Decisions

- Language: Go.
- Dependencies: Go standard library only.
- CLI input: exactly one file path argument.
- Empty lines: ignored.
- Invalid non-numeric lines: return an error.
- Empty files: return an error.
- Variance formula: population variance, using `sum((x - mean)^2) / N`.
- Standard deviation formula: square root of variance.
- Rounding: final printed values use standard rounding.

## Code Structure

- `main.go`: CLI argument handling and program orchestration.
- `internal/io.go`: file reading and number parsing.
- `internal/stats.go`: statistics calculations and output formatting.
- `tests/unit/`: unit tests for parsing and statistics functions.
- `tests/testdata/`: reusable input files for program-level tests.
- `README.md`: run and test instructions for the evaluator.
